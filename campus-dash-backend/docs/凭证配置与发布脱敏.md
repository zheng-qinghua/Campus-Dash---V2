## 环境变量约定

| 变量 | 使用方 | 约束 |
| --- | --- | --- |
| `SPRING_DATASOURCE_PASSWORD` | 主应用、worker、测试、压测及真实验收脚本 | 必填，不提供硬编码默认值 |
| `MYSQL_ROOT_PASSWORD` | MySQL 容器初始化 | 由 Compose 映射同一个 `SPRING_DATASOURCE_PASSWORD`，不另存固定值 |
| `DASH_JWT_SECRET` | 使用 JWT 模式的应用与测试 | 使用 JWT 时必填，至少 32 字节随机密钥 |
| `DASH_INTERNAL_TOKEN` | 内部管理接口与内部压测客户端 | 按需注入，未配置时内部接口拒绝认证 |

环境变量应由运行环境、密钥管理系统或仓库外受控环境文件提供。`.env.example` 只能保留变量名与说明，真实 `.env` 不应进入版本库。前端 `VITE_*` 会进入浏览器产物，不能用于传递任何后端口令或签名密钥。

在启动终端静默输入：

```bash
read -rs SPRING_DATASOURCE_PASSWORD
export SPRING_DATASOURCE_PASSWORD

# 仅在选择 JWT 模式时设置，输入至少 32 字节随机密钥
# read -rs DASH_JWT_SECRET
# export DASH_JWT_SECRET
```

使用仓库外受控环境文件时，依次执行 `set -a`、`source /受控目录/campus-dash.env`、`set +a`。新终端不会自动继承其他终端的变量，需要再次注入。不要用 `echo` 打印口令，也不要把展开环境变量的命令输出上传到仓库。检查 Compose 只使用 `docker compose config --quiet`。

MySQL CLI 从环境读取口令，例如在后端目录执行已有迁移：

```bash
MYSQL_PWD="${SPRING_DATASOURCE_PASSWORD:?请先设置数据库口令}" \
  docker exec -e MYSQL_PWD -i dash-mysql \
  mysql -uroot campus_dash < docker/migrate-p6.sql
```

这只是当前命令写法，不表示本次执行了迁移。禁止把实际口令拼进 `-p`、`--password` 或 Java 命令行参数。已有 MySQL 数据卷不会因改变 `MYSQL_ROOT_PASSWORD` 自动轮换账户口令；曾上传的旧口令需要在数据库侧更换，随后同步运行环境。

全量回归使用 `bash scripts/verify-grab-v2.sh`，该脚本创建独立数据库；若缺少 JWT 密钥，只在本轮进程环境生成随机密钥。直接运行 `mvn test` 需要同时提供 JWT 测试密钥，并避免继承生产数据源 URL。
